# Example Gallery

This folder is prepared for six showcase posters used by the GitHub README.

Replace the placeholder files with your selected final posters and keep the filenames unchanged:

- `poster-1.png`
- `poster-2.png`
- `poster-3.png`
- `poster-4.png`
- `poster-5.png`
- `poster-6.png`

Recommended:
- vertical format
- approximately 5:7
- consistent export resolution
- six visibly different destinations / compositions
- no duplicated layout skeleton

The root README files already contain a 3 × 2 gallery layout referencing these filenames.
